## 1. 工作包内容

- `ydb转换.py`：上部结构提取、兼容列与 `Upper.*` 契约元数据。
- `handoff_atomic.py`：上部/基础范围隔离、UNC 只读连接、暂存校验与原子替换。
- `foundation_handoff.py`：基础源库统一走只读连接。
- `revit_addin/PecStiffenerCommand.cs`：供正式 Revit 插件仓库集成的安全修订参考。
- `tests/`：接口、异常路径与近期缺陷回归。
- `README.md`、`requirements-dev.txt`、`pytest.ini`、`.github/workflows/test.yml`：可复现开发、测试和 Windows 构建入口。
- `handoff_doc/handoff-Revit端-柱偏心旋转与近期接口联动-20260907.md`：交给 Revit 开发的主接口文档。

## 3. 兼容与变更约束

- `tbl1`–`tbl4` 既有列顺序保持，扩展只在尾部或共享 metadata 表中增加。
- 上部提取只能重建 `tbl1`–`tbl4` 与 `Upper.*`；基础提取只能重建 `tbl5`–`tbl7` 与 `Foundation.*`。
- 源 YDB 只读，目标只在暂存副本通过 `integrity_check`、范围哈希与并发检查后原子替换。
- `BIsArc` 行为按现有版本冻结，本次不修改识别结果。
- 本仓库不包含正式 CreateNewExtern 工程，不能替代 Revit 内联调和插件 DLL 发布。

## 5. 发布与部署顺序

1. 从本工作包主分支获取源码、handoff 和 `dist\ydb转换.exe`，核对发布记录中的提交与 SHA-256。
2. Revit 开发按主 handoff 在正式插件仓库完成 P0/P1，编译并记录正式 DLL SHA-256。
3. 在隔离的测试数据库上用新 EXE 重转，不覆盖唯一生产副本；检查 `handoff_meta`、表列和 `PRAGMA integrity_check`。
4. 在干净 Revit 测试模型完成 10 项验收矩阵，特别核对偏心+旋转、真实柱顶、梁偏移和墙斜顶。
5. 关闭 Revit 后替换实际清单所指 DLL，并替换部署目录转换器；重新读取两个文件摘要。
6. 首次运行只对副本模型操作；确认日志中的 SourceSHA256、插件版本、构件计数和亮显数量。

回滚时关闭 Revit，恢复成对备份的插件 DLL 与转换器 EXE；中间数据库用重转前备份恢复。不要只回滚其中一个二进制，否则字段生产端和消费端会再次漂移。
