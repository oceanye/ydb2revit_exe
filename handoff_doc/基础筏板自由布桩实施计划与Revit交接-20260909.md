# 基础筏板自由布桩实施计划与 Revit 交接

日期：2026-09-09  
分支：`feature/foundation-mat-free-piles`  
数据模式：筏板楼板 + 自由单桩  
样本：`基础测试模型/颛桥整体桩基-Jccad_0.ydb`

## 1. 交付目标

将 YJK 中“筏板按厚度/标高分区、桩逐根自由布置”的基础模型转换为 Revit 可消费的两类对象：

1. 每个筏板区域生成一个楼板/筏板实体；
2. 每条 `app_Pile` 记录生成一个独立桩实例；
3. 不创建承台族，不生成承台中心，不把自由桩合并成桩阵列；
4. 每个区域和每根桩保留源 ID、稳定键和 Revit 回写 ID。

当前承台—桩模式继续使用 `tbl5`–`tbl7`，新模式使用独立的 `tbl8`–`tbl9`，两种模式不能混用。

## 3. 第一阶段实现计划：Python 转换器

### 3.1 模式识别

在基础模式中增加只读判定：

- `RaftSlab`、`RaftCornerPoint`、`app_Pile`、`DEF_Pile` 非空；
- `app_dais`/`DEF_dais` 为空，或 `app_Pile.DaisFlag` 全部为负；
- 进入 `raft_free_piles`，不调用现有承台抽取器。

承台 YDB 仍走现有 `pile_caps` 流程；混合文件必须显式报错，不能静默选择其中一种。

### 3.2 输出契约

保留 `tbl5` 桩型表，新增：

```text
tbl8  RaftFloorRegion
      ID, RegionKey, SourceRaftID, SourceLID,
      PolygonJson, Thickness, BottomZ, BaseZ,
      ParentRegionID, UserTypeName, Notes, ExtraJson, UpdatedAt, RvtID

tbl9  FreePile
      ID, SourceID, X, Y, Z, Length, PileTypeID,
      Kind, DaisFlag, SourceUpperID, HostRegionID,
      Notes, ExtraJson, UpdatedAt, RvtID
```

约束：

- 中间库长度统一 mm；`RaftSlab.thick` 原本为 mm；`BotElevat` 乘 1000 后写 `BottomZ`；
- `BaseZ` 原值保留为 mm，直到确认其 YJK 几何语义；
- `PolygonJson` 保存完整边界，统一方向并拒绝少于 3 点/零面积；
- `HostRegionID` 可为空，不能按 XY 强行唯一归属；
- `tbl9` 一行一根桩，禁止把多根桩折叠进 JSON 阵列；
- `tbl5` 通过稳定 `TypeKey` 复用相同桩型，但不复用桩实例；
- 清理范围新增 `tbl8/tbl9`，不得破坏 `tbl1`–`tbl7` 中另一模式的数据。

### 3.3 桩型映射策略

先支持样本单桩型：`DEF_Pile` 只有一行时，`app_Pile.kind=0` 回退到该唯一桩型。多桩型文件必须同时验证 `kind → DEF_Pile.ID` 是否直接映射；若仍存在 0-based 编码，则写入 `ExtraJson` 并在 warnings 点名，禁止静默错配。

## 4. 标高和归属验证计划

### 4.1 `app_Pile.z`

样本中 749 根桩能与空间落区内的 `RaftSlab.BotElevat×1000` 唯一相等，支持将 `z` 暂按“桩顶/筏板底绝对标高 mm”传递。正式实现先保留原字段名 `SourceZ`，并在 metadata 中写明 `Foundation.PileZSemantics=RAFT_BOTTOM_CANDIDATE`，直到用 YJK 剖面或 Revit 对照模型确认。

确认测试：选取一个 `z=-10200`、一个 `z=-5800` 的单桩，在 YJK 截面核对桩顶是否位于相应筏板底；若相反则只调整 Revit 消费端的顶/底解释，不改源值传递。

### 4.2 筏板区域

按 `SourceLID` 输出所有区域，即使区域互相重叠。Revit 端按每区的 `BottomZ`、`Thickness` 创建板；不做区域合并。50 根边界外桩保持 `HostRegionID=NULL`，仍必须生成。

### 4.3 边界双候选

源 ID 577、797 同时落在两个同标高区域边界。第一版不丢弃、不复制桩：`tbl9` 只保留一行，`HostRegionID=NULL`，warning 记录候选区域列表。

## 5. Revit 端交接要求

1. 读取 `Foundation.ContractVersion` 和 `Foundation.Scope`，确认是 `RAFT_FREE_PILES_V1`；
2. 读取 `tbl8`，按 `PolygonJson` 建立楼板边界，厚度使用 `Thickness`，底面使用 `BottomZ`；
3. 读取 `tbl9`，按 `SourceID` 一行一桩，使用 `PileTypeID` 找到 `tbl5` 桩型；
4. `Z` 语义确认前，日志记录原始 Z，不得自动向最近 Level 吸附；
5. 对 `HostRegionID=NULL` 的桩照常生成，并亮显/记录“未归属筏板区域”；
6. 每个 `tbl8`/`tbl9` 实例回写自身 `RvtID`，不得使用区域 ID 覆盖桩 ID；
7. 新模式下不得读取 `tbl6.PileLayoutJson`，也不得调用承台合并逻辑。
