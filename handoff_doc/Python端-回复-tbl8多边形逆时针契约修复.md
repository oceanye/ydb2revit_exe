## 4. 两个知悉项

1. **原顺时针区域的 RegionKey 会变**：RegionKey 由区域数据（含多边形及顶点顺序）哈希而成。
   因此不能保证跨版本稳定；按旧键关联 Revit 元素的流程需要迁移，不能视为无兼容影响。
   重导前保留旧库和元素对应关系，结合相同源模型、SourceLID 和实际几何核对，
   避免把键变化误判为新增区域而重复建板。当前转换重建 tbl8/tbl9 并将 RvtID 置空，不自动迁移旧元素关联。
2. 谢谢你们把硬校验改成"自动反转+日志"的兜底——这层防御与转换器侧的
   归一化形成双保险。当前转换器会去掉相邻重复点及末尾闭合点，并拒绝不足三点或零面积；
   Python 已增加非相邻重复点和自交边界拒绝；Revit 仍需按自身 API 容差做最终可建性校验。
