# Handoff：BIsArc 弧梁识别误报/漏报修正（颛桥实测反馈）

提出日期：2026-09-04
提出方：Revit 插件端（CreateNewExtern 维护）
现象：项目3（颛桥重导，新契约全链首次联调）用户实测：
**大量近似直梁被标红（误报），YJK 真弧梁对应的折梁未标红（漏报）**。
插件端行为正确——日志与数据严格一致（BIsArc=1 恰 60 段，红标恰 60 根），
问题全部在 `ydb转换.py` 的几何弦线链识别（§6 落实记录所述 0.03°~15° 规则）。

## 1. 误报实证（插件端已抽查，可直接复核）

这些是 YJK 分段的直梁（跨节点拆段+坐标微抖），被"≥3 段相连 + 转角 0.03°~15°"
规则误判为弧。**下限 0.03° 远低于直梁抖动噪声（~0.1°）**，是误报主因。

## 2. 漏报实证

用户点名的 YJK 真弧梁（折梁形态）未被标记——需 Python 侧拿到具体样本定位
（可能原因：单节点转角 >15° 上界、链被共节点其它梁打断、或段数/连接条件不满足）。
**请建模侧提供 1~2 处真弧梁的位置（楼层+轴线附近）**，用于调参与回归锁定。

## 3. 修正建议（按判别力排序，可组合）

1. **下限提到 ≥1°**（与插件端梁合并的共线容差 1° 对齐——转角 <1° 的链在合并
   语义里就是直梁，标弧无意义）；更稳妥可取 ≥2°；
2. **单调转向约束**：链上各节点转角**同方向**（叉积同号）——真弧是单调弯曲，
   直梁抖动的微小转角方向随机，此条可几乎排除误报；
3. **链累计转角下限**（如 ≥5°）：整链总转角太小的近直链不标；
4. 上界按真弧样本实测定（若真弧单节点转角 >15°，上界需放宽）；
5. 调整后请以"误报清单（当前 60 段中被剔除的）+ 新命中清单"双双报告，双方核对外，
   建模侧同时在 YJK 数真弧梁总数作为最终基准（此前待核对项）。

## 4. 验收标准

1. 颛桥重转后：§1 所列近直段（87/88/89/174/49/95 等）BIsArc=0；
2. 用户点名的真弧位置 BIsArc=1（折梁各段全部标记）；
3. 插件端零改动——重导后红标自动纠正（多标消失、真弧补红）；
4. result 的 `arc_beam_segments` 与建模侧 YJK 计数一致；回归测试锁定新规则。
