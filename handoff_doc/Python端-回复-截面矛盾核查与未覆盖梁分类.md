### 1.2 叠墅：H350X150 的 6X11 与 8X14 是**两个真实并存截面**

| 类别 | 段数 | 定性 | 处置建议 |

| 槽形 Kind=7（Z=12600） | 20 | 屋面檩条类，真实性待设计方确认 | 确认后归类 |

### 2.2 根因（插件 CombineBeam.cs:255 起，主梁筛选）

入口条件 = **梁端点与柱端点 3D 距离 ≤50mm**（几何球匹配；BSConn/BEConn
的读取在代码中已被注释弃用）。两类漏网与此完全吻合：

1. **两端都不碰柱**的梁（280/346 段）没有任何入口——它们连的是墙或
   主梁（次梁搭主梁、地下室梁连墙、夹层梁等）；
2. **带 Z 偏移/斜屋面**的端点：|BZOffset|>50mm 时球匹配必失配（38 段
   实证），斜屋面柱顶 HDiff 同理（28 段待证实）。

### 2.3 给插件端的修改建议

1. 端点-柱匹配改为 **XY 投影距离 ≤ 阈值 且 |ΔZ| ≤ 容差（建议 500mm）**，
   或直接使用 tbl1 已有的 `BSConn/BEConn`（列 10/11，两端连接标志，
   转换器从 YJK SpBeam 属性提取）作为辅助判据；
2. 为"无柱连接梁"补入口：现有三趟合并完成后，对剩余未覆盖段做**几何
   共线自合并**（同层、同截面、首尾相接、共线），输出为合并梁或单段梁；
3. 过滤虚梁：b=h=100 的 Kind=1 段建议跳过建模（或先出清单征询设计方）；
4. 验收口径：未覆盖段从 346 → 仅剩虚梁(139)+弧梁(2)+待确认檩条(20)，
   即**真实梁 0 缺失**；清单"截面不一致"应从 208 大幅下降（多数为
   错配所致，非真混用）。
