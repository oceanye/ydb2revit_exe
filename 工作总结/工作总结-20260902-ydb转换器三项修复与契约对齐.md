## 二、三项功能修复（均在 ydb转换.py）

### ① tbl3 标高集合多塔缺口（响应插件端 handoff）

* **现象**：颛桥多塔模型斜屋面层顶 16795mm 不衔接任何下一层底，现行
  "各层底 + 末层顶"算法漏掉该标高 → Revit 端 `FindLevelAtElevation` 找不到
  顶部标高（ID=1080），整个建模中止。
* **修复**：tbl3 = ∪各层底 ∪各层(LevelB+Height)，按标高去重（容差 1e-6）；
  脱接层顶命名 RF2、RF3…（不与现有名冲突）；重复底标高保留先出现者。
* **零回归**：连续单栋模型输出与旧版逐行一致（末层 RF 优先占名）。
* 测试：+2 项（多塔缺口复现、连续模型零回归）。

### ② 无尺寸 PEC 截面显式拒绝（颛桥"ShapeVal增强失败"根因）

* **现象**：6 个 Kind-209 梁截面（33502/04/06/07/09/10）在 ydb 的所有
  数值列中尺寸全零，旧代码输出 `209,33506@PEC` 垃圾截面串 →
  Revit 端解析失败、异常弹窗循环。
* **修复**：转换器在**写库前**收集无法解析四尺寸的 PEC 截面，显式报错
  点名 SectID 与受影响构件数（按自然层实例计），正式库分毫不动。
* 测试：+1 项。

### ③ Kind26 热轧 H 型钢打包串解码（颛桥全文件闭环）

依据《YJK Kind26热轧H型钢与Kind209_YDB解析说明》完成：

```text
校验链：[0]=26 → [1..8]解包选择器=39 → 名称(HN/HW/HM) → Q16 的 H/B 与名称交叉一致
       → [14]=0 标准热轧 → [41]尾部ID一致 → 厚度：四段式名称直取 / 两段式查国标表
```

* 两段式名称厚度取自内置 **GB/T 11263-2017** 常用规格表（本机无 sscs 目录，
  待 YJK 侧抽查核对——唯一开放项）。
* **颛桥 dtlmodel.ydb 实测**：7557 梁 / 1759 柱 / 229 墙肢全部转换成功；
  6 个原报错截面 → H600X200X11X17、H500X200X10X16、H400X200X8X13(731根)、
  H400X150X8X13、H300X150X6.5X9、H200X200X8X12；垃圾截面串 0 条。
* 测试：+1 项。

### ④ 截面文本契约对齐 SectionTextParser（只读参考 C# 源码）

权威来源：`E:\revit-external-tool2.git` → `CreateNewExtern/SectionTextParser.cs`

* 新增契约函数：`has_pec_suffix / remove_pec_suffix / parse_h_section_text /
